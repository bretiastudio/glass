# GLASS — Riflesso · launch film

A ~31 s film for the GLASS website, closing on **POWERED BY BRETÌA**. The website is the material: its own built
HTML and CSS are mounted inside the composition and driven frame by frame. Nothing here modifies the site.

Concept round and boards: `concept/CONCEPTS.md`. Final report (Italian): `REPORT.md`.

## Folder

| path | what |
|---|---|
| `comp/comp.html` | the composition: one HTML file, every value a function of `t` (`window.__seek(t)`) |
| `comp/site/` | generated by `tools/build_site.py`: the site's CSS and markup per viewport, Jost, grain, posters |
| `comp/motion.js` | onetake's move library, unchanged (licence: `comp/ONETAKE-NOTICE.md`) |
| `comp/frames/` | film frames, generated by `tools/extract_frames.sh` (not committed) |
| `assets/media/` | the site's two trimmed films, as published on the site |
| `assets/Logo 3D BRETÌA con Mascotte Blu.png` | the official BRETÌA logo, untouched master (transparent PNG) |
| `assets/bretia-logo.png`, `bretia-logo-mono.png` | working copies made by `tools/prepare_logo.py`: the original (used), the monochrome study |
| `tools/score.py` | the sound: original synthesis in one room, timed from the composition's `__events()` |
| `tools/rest_check.py` | pre-render stillness check at 320 px |
| `out/` | renders, contact sheets, probe and verify reports |

## Rebuild and render

Requires Python 3 with `playwright` (Chromium), `numpy`, `scipy`, `Pillow`, `matplotlib`, `opencv-python`;
`ffmpeg`; the onetake skill at `~/.claude/skills/onetake` (or `ONETAKE=`); the built site (`npm run build` on
branch `claude/great-shannon-r0o8rk`).

```bash
python3 -I tools/build_site.py /path/to/glass-site/dist
```

```bash
tools/extract_frames.sh
```

```bash
python3 -I tools/prepare_logo.py "assets/Logo 3D BRETÌA con Mascotte Blu.png"
```

```bash
python3 -I tools/score.py
```

```bash
python3 ~/.claude/skills/onetake/scripts/render.py comp/comp.html --out out/draft.mp4 --sfx out/sfx.wav --gap 2.5 --samples-max 64
```

```bash
python3 ~/.claude/skills/onetake/scripts/verify_promo.py out/draft.mp4 --comp comp/comp.html --shots 0,0.5,2.95,4.5,7.9,9.3,10.1,11.45,12.25,13.0,13.68,14.72,15.75,16.55,18.85,19.75,20.15,21.45,22.55,23.5,25.3,27.6,28.45,31.5
```

`--gap 2.5` keeps the shutter's copies close enough that thin type smears instead of stepping (the default 6 px
left visible copies on the scrolling text in the first draft).

Preview in a browser: `comp/comp.html?play`, or pin a frame with `comp/comp.html?t=6.4&hud`. The monochrome
logo study: `?logo=mono`. The 4K60 master (`render.py … --final`) is rendered only after the draft is approved.
